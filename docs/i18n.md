# ლოკალიზაცია

## სტრუქტურა

```
src/i18n/index.ts          i18next-ის ინიციალიზაცია და ენის შენახვა
src/i18n/locales/ka.json   ქართული (ძირითადი)
src/i18n/locales/en.json   ინგლისური (fallback)
```

## ენის შერჩევა

1. AsyncStorage-ში შენახული არჩევანი (`ies.language`), თუ არსებობს.
2. სხვა შემთხვევაში მოწყობილობის ენა `expo-localization`-იდან: `ka` → ქართული,
   დანარჩენი → ინგლისური.

## გამოყენება

```tsx
import { useTranslation } from 'react-i18next';

const { t } = useTranslation();
<Text>{t('list.title')}</Text>
```

## ენის შეცვლა

```ts
import { changeLanguage } from '../src/i18n';
await changeLanguage('en');
```

## გასაღებების ორგანიზება

გასაღებები დაჯგუფებულია ეკრანების მიხედვით: `tabs.*`, `list.*`, `event.*`,
`map.*`, `settings.*`. ორივე ფაილს ერთი და იგივე სტრუქტურა უნდა ჰქონდეს —
`en.json` fallback-ია და ნაკლული გასაღები ინგლისურ ტექსტს გამოიწვევს ქართულ UI-ში.

## წესები

- ინტერფეისში ტექსტი პირდაპირ არ იწერება — მხოლოდ `t()`-ით.
- ახალი გასაღები ერთდროულად ემატება `ka.json`-სა და `en.json`-ს.
- რიცხვები და თარიღები `src/utils/format.ts`-ით ფორმატირდება, არა თარგმანებით.
