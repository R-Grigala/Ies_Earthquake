# რუკა

**მარშრუტი:** `app/(tabs)/map.tsx`
**სტატუსი:** 🔜 დაგეგმილი

## დანიშნულება

მოვლენების გეოგრაფიული განაწილება საქართველოსა და მიმდებარე რეგიონზე.
მარკერზე დაჭერით ჩანს მოკლე ინფორმაცია, callout-იდან — სრული დეტალები.

## მონაცემები

| წყარო | აღწერა |
| --- | --- |
| `useEarthquakes()` | იგივე ქეში, რასაც სია იყენებს — ტაბებს შორის გადასვლა ხელახლა არ ითხოვს ქსელს |

## რუკის კონფიგურაცია

| პარამეტრი | მნიშვნელობა |
| --- | --- |
| საწყისი ცენტრი | 42.0186, 43.9911 (საქართველო) |
| delta | 10 / 10 |
| `mapType` | `standard` (light) / `hybrid` (dark) |
| მომხმარებლის ლოკაცია | გამორთული — ნებართვა არ ვითხოვთ პირველ ვერსიაში |

## მარკერები

მარკერი სისტემური `Marker`-ია, ფერით და ზომით — გამოსახულებები არ იტვირთება
ქსელიდან (GNSMC-ში აიკონები სერვერიდან მოდიოდა და ოფლაინში ქრებოდა).

| მახასიათებელი | წყარო |
| --- | --- |
| ფერი | `magnitudeColor(magnitude)` |
| ზომა | `magnitudeMarkerSize(magnitude)` |
| გამჭვირვალობა | `eventAge()`: `recent` 1.0, `month` 0.7, `older` 0.4 |
| `key` | `event.id` |

## Callout

დრო (UTC), კოორდინატები, მაგნიტუდა, სიღრმე; დაჭერით → `/event/[id]`.

## ლეგენდა

ქვედა კუთხის პანელი: მაგნიტუდის ფერები და ასაკის სამი დონე
(`map.legendRecent`, `map.legendMonth`, `map.legendOlder`).

## მდგომარეობები

| მდგომარეობა | რას აჩვენებს |
| --- | --- |
| loading | რუკა იხატება, მარკერების გარეშე |
| error | ბანერი რუკის ზემოთ, `list.error` + retry |
| empty | რუკა მარკერების გარეშე |
