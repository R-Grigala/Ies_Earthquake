# მოვლენის დეტალები

**მარშრუტი:** `app/event/[id].tsx`
**სტატუსი:** 🔜 დაგეგმილი

## დანიშნულება

ერთი სეისმური მოვლენის სრული აღწერა და ეპიცენტრის მდებარეობა რუკაზე.

## მონაცემები

| წყარო | აღწერა |
| --- | --- |
| `useLocalSearchParams()` | მარშრუტიდან `id` |
| `useEarthquake(id)` | ეძებს მოვლენას `useEarthquakes()`-ის ქეშში |

მოვლენის მონაცემები ნავიგაციის პარამეტრებით **არ** გადაეცემა — მხოლოდ `id`.
GNSMC-ში ყველა ველი route params-ში იგზავნებოდა, რაც ინფორმაციას აყინავდა და
ფორმატირებას ნავიგაციის შრეში ატანდა.

## UI ელემენტები

- მაგნიტუდის დიდი ბეიჯი, ფონი `magnitudeColor()`-იდან.
- ველების ცხრილი: დრო (UTC), ადგილობრივი დრო, კოორდინატები, სიღრმე, რეგიონი.
- პატარა რუკა ერთი მარკერით, ეპიცენტრზე დაზუმებული (delta 1.5).

## მდგომარეობები

| მდგომარეობა | რას აჩვენებს |
| --- | --- |
| loading | `ActivityIndicator` |
| მოვლენა ვერ მოიძებნა | `event.notFound` + უკან დაბრუნების ღილაკი |
| error | `list.error` + retry |

„ვერ მოიძებნა" რეალური სცენარია: ეკრანი პირდაპირი ლინკით შეიძლება გაიხსნას,
სანამ სია ჩაიტვირთება, ან მოვლენა API-ს პასუხიდან გავარდეს.

## ნავიგაცია

შემოსვლა სიიდან ან რუკის callout-იდან; უკან — stack-ის header.

## ლოკალიზაცია

`event.timeUtc`, `event.timeLocal`, `event.magnitude`, `event.depthKm`,
`event.latLong`, `event.region`, `event.notFound`.
