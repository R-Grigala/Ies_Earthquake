# მიწისძვრების სია

**მარშრუტი:** `app/(tabs)/index.tsx`
**სტატუსი:** ⏳ მიმდინარე (მონაცემთა შრე მზადაა, UI იწერება)

## დანიშნულება

აპის საწყისი ეკრანი: უახლესი სეისმური მოვლენების ქრონოლოგიური სია, ახლიდან
ძველისკენ. მომხმარებელი აქედან გადადის კონკრეტული მოვლენის დეტალებზე.

## მონაცემები

| წყარო | აღწერა |
| --- | --- |
| `useEarthquakes()` | დროით დალაგებული `EarthquakeEvent[]`, 30 წმ `staleTime`, 60 წმ auto-refetch |

სორტირება `src/api/events.ts`-ში ხდება, ეკრანი დამატებით არ ალაგებს.

## UI ელემენტები

- სათაური — `list.title`, თემის `headerBackground` ფონზე.
- `FlatList` — `keyExtractor` არის `item.id` (არა ინდექსი).
- სიის ერთეული: მაგნიტუდის ბეიჯი (ფონი `magnitudeColor()`-იდან), რეგიონი,
  UTC დრო `formatUtcDateTime()`-ით, სიღრმე.
- `RefreshControl` — pull-to-refresh იძახებს `refetch()`-ს.

## მდგომარეობები

| მდგომარეობა | რას აჩვენებს |
| --- | --- |
| loading (პირველი ჩატვირთვა) | ცენტრში `ActivityIndicator` |
| refetching | `RefreshControl`-ის ინდიკატორი, სია რჩება ხილული |
| empty | `list.empty` + „სცადეთ ხელახლა" ღილაკი |
| error | `list.error` + `list.retry` ღილაკი, რომელიც `refetch()`-ს იძახებს |

მნიშვნელოვანია: ცარიელი პასუხი და შეცდომა ცალ-ცალკე მდგომარეობებია. GNSMC-ში
ორივე ერთნაირად „კავშირი არ არის" ეკრანად ჩანდა.

## ნავიგაცია

ერთეულზე დაჭერა → `/event/[id]`, გადაეცემა მხოლოდ `id`; დანარჩენს დეტალების
ეკრანი ქეშიდან იღებს.

## ლოკალიზაცია

`list.title`, `list.empty`, `list.error`, `list.retry`, `event.magnitude`,
`event.depthKm`, `event.timeUtc`.
