# მიწისძვრების სია

**მარშრუტი:** `app/(tabs)/events.tsx`  
**სტატუსი:** ✅ მზადაა  
**კომპონენტი:** `src/components/events/EventListItem.tsx`

## დანიშნულება

აპის საწყისი ეკრანი. აჩვენებს IES API-დან უახლეს სეისმურ მოვლენებს ქრონოლოგიურად (ახალი ზემოთ).

## მონაცემები

| წყარო | აღწერა |
| --- | --- |
| `useTabEarthquakes()` | ტაბებზე — პირველი ჩატვირთვა + ფონური refetch ტაბის focus-ზე (სპინერი არა) |
| `useEarthquakes()` | დეტალების ეკრანზე — მხოლოდ cache, ტაბის refetch არა |
| `useEventRegion(event)` | მდებარეობის ტექსტი ენის მიხედვით |

## UI

### სათაური

- ტექსტი: **„უახლესი მიწისძვრები"** / **„Latest earthquakes"** (`t('events.title')`)
- წითელი/მუქი თემის ფერი, ქვედა საზღვრით (GNSMC სტილი)

### სიის ერთეული (`EventListItem`)

დაჭერა → `/event/{id}` (დეტალების ეკრანი).

```
┌─────────────────────────────────────────────┐
│ დრო (UTC):  28-08-2026      │  მაგნიტუდა: │
│             05:45:32        │     5.3     │
├─────────────────────────────────────────────┤
│ მდებარეობა:    ქალაქი ონი - ...               │
└─────────────────────────────────────────────┘
```

| ელემენტი | აღწერა |
| --- | --- |
| დრო | ორ ხაზად: `formatUtcDate` + `formatUtcTime`, მარცხნივ |
| მაგნიტუდა | ~30% სიგანე, ცენტრში, ფერი `magnitudeColor()` |
| მდებარეობა | `useEventRegion()` — `location_ge` (ka) / `location_en` (en) |
| ლეიბლები | 88px სიგანის სვეტი, მარცხნივ გასწორება, i18n |

### მაგნიტუდის ფერები

| მაგნიტუდა | ფერი |
| --- | --- |
| > 5 | წითელი `#ff0000` |
| > 4 | ნარინჯი `#ff7b00` |
| > 3 | იისფერი `#aa00ff` |
| ≤ 3 | მუქი `#1c1c1e` |

## მდგომარეობები

| მდგომარეობა | UI |
| --- | --- |
| loading | `ActivityIndicator` ცენტრში |
| error | შეტყობინება + დეტალი + „სცადეთ ხელახლა" |
| empty | „მონაცემები არ მოიძებნა" + retry |
| refetching | `RefreshControl` (pull-to-refresh) |

## ნავიგაცია

- აპის გახსნა → პირდაპირ ეს ეკრანი (`app/index.tsx` redirect)
- ერთეულზე დაჭერა → `/event/{id}`
